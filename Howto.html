How to play

    set up

    • Open the game page in your web browser.
    • identify your side: payerq1 or palyer2

    Rolling the Dice

    • To roll the dice, simply refresh the page (click the browser's reload icon or press Crtl + R / cmd +R).
    • The system will automatically generate a random number from 1 tp 6 for each player and display the corresponding dice faces on the screen.

    Determining the Winner

    Once the page loads, the game evaluates the results instantly

    • Player 1 wins: If player 1's die is higher than player2's fir.
    • Player 2 wins: If player 2's die is higher than player 1's die
    • Draw/Tie: If both players roll the exact smae number.
    Game Rules
    • No Manual Inputs: Players do not manually pick numbers. The game relies entirely on a Random Number Generator (RNG) built into the code.
    • Immediate Settlement: Each refresh constitutes exactly one complete round. Previous scores are wiped clean unless you have a persistent scoreboard active.
