# Module2 Project
Project Requirements:

3 HTML pages
One Page should be a Home / Landing Page that has links to the other pages on your site.
3 JS files. Each HTML page should also have it's own JS file to make its content dynamic.
A CSS page that is linked to all html pages.
Your project should have files that are organized, and appropriately named.
Please review the github pages documentation for guidance on deploying from your own repository.

Potential Project Ideas

A professional website that includes a contact page and a CV page
A Javascript Powered web game
An E-Commerce Site
A Marketing Website for an event that includes with a registration form
